二、用 AI 功能前，先配一次 Key（30 秒，只配一次）

   1. 打开工作台，首页第一张卡就是「论文完成度 和 API 设置」
   2. 服务商选 DeepSeek（默认）
   3. 填你自己的 DeepSeek API Key
      - 注册：platform.deepseek.com（手机号即可，新用户有免费额度）
      - 获取：控制台 → API Keys → 创建
   4. 点「保存配置」，显示"已启用"就好了

   不配 Key 也能用：自检本章（AI 味扫描）、计量分析、图表预览、文献管理、AI 排版
   配了 Key 才完整：AI 写全文、润色、审稿、降重、提炼摘要这些

   放心两点：
   · Key 只存在你自己的浏览器里，同事看不见、我也收不到
   · 但文本会发给 DeepSeek 处理，别往里贴学生身份证号之类的敏感信息

四、写论文建议这么走

   1. 先去「教科研论文写作技巧」看一遍字数和结构要求，心里有数
   2. 「检索与前沿」找方向、看文献
   3. 「文献阅读与笔记」把读到的存下来，顺手让 AI 提炼创新点
   4. 回「AI写论文」新建文稿，按 8 章模板一章一章写
   5. 每写完一章，点底栏「自检本章」——它会告诉你哪句话像 AI 写的、哪里还留着 [待补充]
   6. 全文写完，「AI 降重」过一遍，「AI 审稿」让 AI 挑刺
   7. 定稿前「AI 排版」排成规范格式，再导出

   ⚠️ 一条底线：所有 [待补充：__] 都是占位符，工具不会替你编数据，投稿前必须换成真实数据或删掉。

五、常见问题

   Q：手机打开只有第一页？
   A：首页有「全部功能导航」卡片，直接点模块；或点左上角「菜单」。

   Q：打开是旧页面？
   A：按 Ctrl+F5 强刷（手机：清缓存或用无痕模式）。

   Q：我写的东西别人看得到吗？
   A：看不到。数据只存在你自己浏览器里，不上传服务器，每人独立。

   Q：能帮我检测 AI 率吗？
   A：「AI 降重」里有「AI 率检查」和「检查 AI 味」可自查；
      但正式检测以学校/期刊指定的工具为准（知网/维普/PaperPass）。

   Q：想换电脑/手机，数据怎么带过去？
   A：「数据管理与说明」→「导出 JSON 备份」→ 新设备「导入恢复」。

   Q：在线版写的东西，离线版能看到吗？
   A：看不到，这是两套数据。建议固定用一种方式写。
