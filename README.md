# 职教辅助论文写作平台（Paper Workbench）

> 当前版本：**v2.2**（2026-10-23）· 13 个模块 · 单文件 743,360 字节

一个面向**中小学/中职教师**的论文写作全流程工作台。纯前端单文件 HTML，零依赖、零运维、离线可用，手机电脑双适配。

## 📦 功能详解（13 个模块）

> 按界面左栏顺序：**写作核心 4 个** → **研究工具 6 个** → **数据与系统 3 个**。

### 1. 论文完成度 和 API 设置（首页）
- **用途**：总览写作进度；全平台只在这一处配 AI 模型
- **功能点**：完成度百分比环 · 章节进度网格（24px 三态圆点：未写/进行中/已完成，点击直达写作）· 总字数/目标字数 · **今日要处理**置顶（逾期/待办一键处理）· 全部功能导航卡片 · **智能体 API 设置**（服务商 / API Key / 模型名 / 深度思考开关 / 连接测试）
- **不需要 Key**；首次打开自带示例文稿（含 1 条逾期，演示效果）
- ⚠️ **数据按浏览器来源隔离**：本地 `file://` 打开与线上链接是两套数据，换浏览器/换电脑也各是一套。迁移请先「导出 JSON 备份」

### 2. AI 写论文（核心）
- **用途**：写论文正文
- **支持 4 类文稿**：教科研论文（浙江评比）/ 教学案例 / 期刊论文 / 毕业论文——按类型自动生成章节模板
- **章节编辑**：左侧章节目录（状态圆点 + 字数徽标 + 改名/删除）· 正文编辑（Markdown 支持）· 写作要点（首条常显、可展开全部）· 中英文分项字数 · 1.2 秒自动保存
- **10 张 AI 工具卡**：① 提炼摘要 ② 课程思政 ③ 思维导图 ④ 数据图表 ⑤ 插入实证分析 ⑥ 写作风格样本 ⑦ 创新点设计 ⑧ 案例素材→论文 ⑨ 论文→教学案例 ⑩ 从文献库引用
  - 另配「**功能区对照速查**」面板：每个工具干什么、作用于哪里、什么时候用
- **章节底栏 2 个工具**：
  - 🔍 **自检本章**（本地规则，**零 Key 可用**）：37 条 AI 套话正则扫描 + `[待补充]` 占位符统计 + 本章字数 vs 建议篇幅，命中逐条列出并附改法
  - 🤖 **AI 润色本章**（需 Key）：按本章写作要点重写，保留观点/数据/案例，修病句、去 AI 套话；超 2500 字只润前半段，替换前二次确认
- **文档管理**：新建 / 导入（txt/md/docx 上传自动拆分）/ 导出 Markdown · 更多菜单（重置章节 / 版本快照 / 历史版本恢复）
- 纯本地功能无需 Key；AI 工具需 Key

### 3. 教学评比
- **用途**：管理教学评比任务与通知
- **功能点**：评比任务台账（单位/名称/级别/截止/字数要求/进度/材料）· **评比通知库**（内置示例，可增删、可临时隐藏本机内置数据）· 紧凑行样式（`.crow` 类族），≤600px 自动折行
- 无需 Key
- 📌 2026-09-12 起已移除「投稿追踪 / 期刊库 / 智能选刊」三项，查刊请用「检索与前沿」的数据库直达

### 4. 教科研论文写作技巧
- **用途**：浙江获奖论文的硬性指标速查
- **功能点**：硬性指标 · 字数配比（如教科研 15-10-10-50-10）· 六大理论框架 · 2026 评审趋势，共 4 篇精华
- 无需 Key

### 5. 文献阅读与笔记
- **用途**：管理读过的文献，沉淀论文素材
- **功能点**：文献增删改（标题/作者/期刊/年份/DOI/笔记/标签）· **创新点挖掘**（粘贴文献→生成创新方向）· **总结本文创新点** · **AI 结构化笔记**（基本信息/核心贡献/研究问题/关键方法/主要结论/与我研究关联，关联点带 6 种类型+相关度评分）· **AI 精读**（针对具体问题：原文引用→批判三段→一句话回答，防幻觉不编造）· 一键导入写作页引用
- **不需要 Key** 可用基础管理；AI 功能配 Key 后完整

### 6. 检索与前沿
- **用途**：查文献、找方向、出综述
- **功能点**：8 大数据库直达（知网/万方/WOS/Google Scholar 等）· 4 大查重入口（知网/维普/万方/PaperPass）· **前沿方向挖掘**（国家大新闻+社会痛点→研究方向）· **主题综述生成**（输入主题→背景/现状/热点/空白/启示五段式）· 三段式合并布局，生成中显示不确定进度条（真实完成才切换，不按定时器跳数）
- AI 功能需 Key

### 7. AI 降重
- **用途**：降低查重率、去 AI 痕迹
- **6 大工具**：AI 润色本段 · 逐句精修（原文→改进→理由）· 审稿人挑刺 · AI 率检查 · AI 降重（按连续 13 字符查重原理三轮降重）· 去 AIGC（连接词密度/句长/完整性偏差→结构级重写）
- **检测原理速查**：查重原理（13 字符）· AIGC 检测三指标 · 平台差异（知网 35%、万方 12% 属正常）· 反直觉认知（"写得越好越容易被判 AI"）
- 需 Key

### 8. AI 审稿
- **用途**：投稿/评比前让 AI 审一遍
- **4 类类型差异化**：教科研（选题现实性/实践性/成果价值/论证逻辑/语言规范）、案例、期刊、毕业论文（依据教育部教督〔2020〕5号）
- **7 模块报告**：执行摘要 · 优点 · 不足（按高/中/低严重度）· 贡献评估 · 文献定位 · 可操作建议（必须改/建议改/可选）· 维度评分条
- **配套检查**：引用核验（[n] 与参考文献比对）· 投稿预检清单 · 格式自查 · 期刊匹配 · 防锚定复审
- 导出报告（MD/TXT/DOC）· 未配 Key 用本地模板估算

### 9. AI 助手
- **用途**：通用 AI 对话（问问题、要灵感）
- 需 Key（未配则本地模板回答）

### 10. AI 排版
- **用途**：把草稿排成规范格式
- **功能点**：导入文档/粘贴文本 → 选模板（学术 / 浙江论文 / 自定义）→ 排版预览 → 导出 md/txt/Word
- Word 转换由对话触发（docx-editor-cn）；纯排版本地完成

### 11. 计量分析
- **用途**：教师问卷/成绩数据做简单实证
- **5 步流程**：导入数据（粘贴/CSV/上传）→ 预处理 → 描述统计 → 相关性/OLS 回归 → 导出（Markdown/CSV，可插入论文）
- **全本地计算**（不调用 AI），无需 Key；正式投稿建议用 Stata/R 复核

### 12. 数据管理与说明
- **外观**：浅色/深色主题（全站双主题变量，禁硬编码色）
- **数据管理**：导出 JSON 备份 · 导入恢复 · 单模块导出 · 清空数据（二次确认）· 清空示例
- **平台功能与原理说明**：24 项溯源，见下方完整章节

### 13. 问题反馈
- **用途**：发现问题、提建议直接发给维护者
- **功能点**：一键复制反馈模板 · 一键发邮件（51336843@qq.com）· 扫码微信联系作者

## 🧩 平台功能与原理说明（功能溯源）

> 本平台功能并非凭空实现——每个功能都借鉴了开源 SKILL / 方法论，或采用了明确的原理机制。以下为完整溯源表（★ = 已深读原仓库全文后落地）。

### 核心功能溯源

**1. 论文完成度看板**
- 参照：自有实现
- 原理：章节字数/目标字数实时统计 → 完成度百分比；8 章节网格点亮=已写

**2. 期刊库画像引擎 / 智能选刊（2026-09-12 已下线）**
- 参照：自有 n-gram 算法；流程参考 Paper-Pilot-Skills 思路
- 原理：中文 2-4 字 n-gram 分词 → 停用词过滤 → 碎片清理 → 长度/年份加权 → 词频权重画像 → 饱和函数打分排序
- 现状：功能线整条移除（投稿追踪 / 期刊库 / 智能选刊），此处只留技术记录；查刊请用「检索与前沿」的数据库直达

**3. 图表顾问（计量）**
- 参照：scipilot-figure-skill（Haojae，MIT）★全文级
- 原理：先思考后绘图：按论证目标+样本量+变量类型推荐图型；禁饼图、小样本禁均值柱、防双 Y 轴制造虚假相关

**4. 计量分析（5 步）**
- 参照：自有（浏览器本地计算）
- 原理：OLS 回归矩阵运算 + 描述统计/相关分析，全本地计算；SVG 图表；Stata/R 脚本导出

**5. AI 率检查**
- 参照：humanizer-academic-zh（45★）★全文级 + cn-humanizer 补充
- 原理：LLM 全模式识别：客套话/AI 免责/谄媚语气/模板排比/万能句式/机械节奏等 25 条模式 → AI 痕迹等级判定 + 逐句标注

**6. AI 降重**
- 参照：aigc-reduce（479★）★全文级 · 三轮降重协议
- 原理：划禁改片段 → 词级替换+句级重构（减法）→ 注入书面学术特征（加法）→ Anti-AI 自检；铁律：禁止 AI 全量重写
- 2026 升级：新增「第 0 步·理解查重原理」：连续 13 字符相同判重 → 打破连续表达 6 手法（同义替换/句式重构/语序调整/增删/视角转换/比喻场景化）；专业术语/数据/引用编号禁改

**7. 去 AIGC**
- 参照：cn-humanizer-academic ★全文级（ranranrannervous）
- 原理：5 大重写策略（打破工整结构/破坏过度流畅/抽象转具体/研究者口吻/词级清扫）+ 7 条硬约束（引用守界/内容守界/字数≤1.2倍等）
- 2026 升级：新增「检测原理」：高频连接词连用≥5 次风险+42% / 平均句长>32 字 / 内容完整性偏差 → 口语化转折、长短句交错、注入具体细节（勿编造）、每章选 1 论点强化立场；「第 5 步·注入灵魂」：节奏变化/适度不完美/具体细节胜过概括/避免三件套与虚假升华；Anti-AI 自检扩到 12 项

**8. 检查 AI 味**
- 参照：自有规则（AI_PATTERNS）+ humanizer 家族词表
- 原理：正则扫描 AI 高频表达 + 替换建议，本地免费快检，不联网
- 2026 升级：37 条本地正则（吸收 AI 痕迹消除专家 humanizer v2.1.1 + 用户本机 unclecheng-reduce-ai-perception-v2（humanizer v3.1，整合 Wikipedia/stop-slop 7.3k★/Humanizer-zh 8.6k★/oh-story 1.7k★/ai-flavor-remover 1k★/khazix-writer））——模式覆盖：模糊归因/空洞积极结尾/重要性膨胀/过度模糊/破折号/回避系动词/公式化回指/二元对比"不是X而是Y"/学术衔接套话/填充短语/踩雷词/教科书开头/金句"静待花开"式表达等；结果「原文标注视图」标黄+悬停建议

**9. AI 审稿**
- 参照：citation-check-skill + Nature-Paper-Skills 思路 + v2 视频方法论；「毕业论文」维度依据教育部教督〔2020〕5号抽检办法；报告结构升级借鉴 academic-paper-review（字节 DeerFlow 77k★）7 模块审稿规范
- 原理：4 种类型×5 维度差异化打分（毕业论文=选题意义/写作安排/逻辑构建/专业能力/学术规范，官方文件对齐；评奖重实践支撑，教学案例不催参考文献）；引用核验（[n] 与参考文献比对）；投稿预检清单（按文稿类型动态生成）；期刊匹配（n-gram 画像）；报告含 7 模块：执行摘要/优点/不足（按严重度分级）/贡献评估/文献定位/可操作建议（必须改-建议改-可选）/维度评分

**10. 创新点设计**
- 参照：RW Research Skill（rw-research-novelty）★全文级 + Paper-Novelty-Design（伪创新诊断/三层陈述/可证伪性/压力测试）
- 原理：证据问题卡（区分没研究/没找到/没报告/没测量/真冲突/假冲突）→ 头脑风暴 → 硬性反驳 → 新颖性四状态 → 7 维分开打分；升级为 9 步：+ 伪创新诊断 5 型 + Problem-Method-Insight 三层陈述 + 可证伪性转化命题表 + 压力测试 5 项

**11. 研究设计引导**

- 原理：研究问题→核心理论→变量关系→推导假设 H1-H3→检验方法 五步引导

**12. 论文大纲导图**

**19. 摘要一键提炼**

**20. AI 结构化文献笔记**

- 参照：paper-quick-reader deep-dive 协议

## 🔑 AI 功能与 Key 配置（同事必看）

工作台 AI 功能（审稿/降重/提炼/创新点等）调用大模型 API，**每人配自己的 Key**（只存在各自浏览器，安全互不干扰）：

1. 打开网页 → 首页「论文完成度 和 API 设置」卡片里填 Key
2. 服务商选 **DeepSeek**（或任意 OpenAI 兼容服务）
3. 填入你的 **DeepSeek API Key**
   - 注册：https://platform.deepseek.com （手机号注册，新用户有免费额度）
   - 获取：控制台 → API Keys → 创建
4. 点「保存配置」→ 状态显示"已启用"即可

**常见问题**：
- 不配 Key 能用吗？→ 能。本地功能（AI 味检查、计量分析、图表预览、文献管理）不受影响；AI 生成类功能走"本地模板"（给框架不给完整结果）
- Key 会被别人看到吗？→ 不会。存在你自己浏览器的 localStorage，不上传任何服务器；别人打开网页是独立环境
- 想换服务商？→ 服务商选"自定义"，填 baseUrl + 模型名即可（兼容 OpenAI 格式的服务都能用）

## 💾 数据安全与备份迁移

- **存储**：所有数据保存在浏览器 localStorage（本机/本浏览器），不上传服务器
- **备份**：设置页 →「导出 JSON 备份」→ 保存文件（数据满 30 条会提醒）
- **迁移**：换电脑/清缓存前先导出，新设备「导入恢复」即还原
- **清空**：二次确认，防误删

## 🛠 技术说明

### 架构
- **单文件 HTML**：全部 CSS/JS/图标内联，`index.html` 一个文件即完整应用
- **零外部依赖**：不引用任何 CDN/框架/字体库（避免离线或 404 失效）
- **图表**：内联 SVG 手写（进度环/柱状图/折线图/散点图/箱线图等），无图表库
- **图标**：内联 SVG path，非 emoji
- **字体**：系统字体栈（-apple-system/Segoe UI/Roboto）

### 数据存储
- localStorage，key 统一前缀 `paperwb_`（如 `paperwb_docs`、`paperwb_literature`、`paperwb_settings`）
- 单域名约 5MB，纯文本几千条足够
- 文稿/文献/设置/版本快照均本地存储

### AI 集成
- 调用 OpenAI 兼容 API（默认 DeepSeek，支持自定义 baseUrl）
- 未配 Key 自动降级本地模板，功能不报错
- 所有 AI 调用在浏览器端发起，无后端服务器

### 响应式
- ≥1100px 三栏布局（导航+内容+详情）；768-1100px 两栏；<768px 单栏+抽屉菜单
- 移动端：按钮 ≥44px、输入框 ≥16px（防 iOS 缩放）、适配底部安全区
- 悬停功能简介（data-tip 卡片），移动端自动隐藏

### 兼容性
- 现代浏览器（Chrome/Edge/Safari/Firefox），手机 Android/iOS 均可
- 微信内置浏览器可用，建议右上角"在浏览器打开"更稳定
