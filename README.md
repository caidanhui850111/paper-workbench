# 职教中心写论文平台（Paper Workbench）

一个面向**中小学/中职教师**的论文写作全流程工作台，纯前端单文件 HTML，零依赖零运维。

## 🚀 在线使用（GitHub Pages）

👉 https://caidanhui850111.github.io/paper-workbench/

手机浏览器打开即可使用，可"添加到主屏幕"当 APP 用。数据保存在浏览器本地（localStorage），刷新不丢失。

## ✨ 功能一览（10 个模块）

| 模块 | 功能 |
|---|---|
| 论文完成度 | 章节进度、字数统计、今日要处理置顶 |
| 文献阅读与笔记 | 文献管理、创新点挖掘、AI 结构化笔记、AI 精读 |
| 检索与前沿 | 数据库/查重入口、前沿方向挖掘、主题综述生成 |
| 论文框架与写作 | 4 类文稿模板、章节编辑、AI 工具（提炼摘要/研究设计/创新点/课程思政/数据图表/大纲导图） |
| 论文评比与投稿 | 评比任务（浙江要求）、投稿追踪、期刊库、智能选刊 |
| 计量分析 | 数据导入→描述统计→OLS 回归→导出（全本地计算） |
| AI 降重 | AI 润色/逐句精修/审稿人挑刺/AI 率检查/AI 降重/去 AIGC |
| AI 审稿 | 4 类类型×5 维度审稿 + 7 模块报告（执行摘要/优点/不足/贡献/建议） |
| AI 助手 | 通用 AI 对话 |
| 设置与说明 | LLM 配置、主题、数据备份恢复、24+ 项功能溯源 |

## 🔑 同事一起用：AI 功能如何配 Key（重要）

工作台 AI 功能（AI 审稿/降重/提炼摘要等）需要大模型 API Key，**每位使用者各自配置自己的 Key**（Key 只存在各自的浏览器里，互不干扰、安全）：

1. 打开网页 → 左侧「设置与说明」
2. 服务商选 `DeepSeek`（或其他 OpenAI 兼容服务）
3. 填入你的 **DeepSeek API Key**（到 https://platform.deepseek.com 注册获取，有免费额度）
4. 点「保存配置」，状态变为"已启用"即可使用完整 AI 功能

> 不配 Key 也能用：本地模板模式（AI 味检查、图表预览、计量分析等纯本地功能不受影响）。
> 详细步骤与常见问题见下方「使用说明」。

## 📝 使用说明

### 数据安全
- 所有数据保存在浏览器 localStorage，不上传任何服务器
- 建议定期：设置页「导出 JSON 备份」→ 保存到本地文件
- 换设备/清缓存前先导出备份，之后「导入恢复」即可迁移

### 手机使用
- 手机浏览器打开链接 → 右上角「···」→「添加到主屏幕」→ 像 APP 一样用
- 首页有「全部功能导航」卡片，无需菜单也能直达所有模块

### 隐私提示
- GitHub Pages 为公网可访问，页面不预填任何真实隐私数据
- AI 功能调用时，文本会发送到你所配 Key 对应的服务商（DeepSeek），请注意不要在未配 Key 时输入敏感内容

## 🛠 技术说明

- 单文件 HTML，全部 CSS/JS/图标内联，无外部依赖（可离线）
- 图表为内联 SVG 手写，图标为内联 SVG
- 功能原理与 SKILL 溯源见平台内「设置与说明 → 平台功能与原理说明」（24+ 项）
